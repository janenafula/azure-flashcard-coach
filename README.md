# Azure Flashcard Coach

Help me build an AI-powered app using Lovable AI.

Build a web app called Azure Flashcard Coach, an official A Z- 900 study tool. Show one flashcard at a time with an Azure term on the front. Clicking the card flips it to show a short plain English explanation on the back. A next and previous buttons, a shuffle button, and a progress counter like card 3 of 12. Start with 12 placeholder cards on a core A Z - 900 topic. Use a clean, friendly design with a brighter color theme. Add a small footer that says, "An official study tool not affiliated with Microsoft." Do not use any Microsoft logos.

This project was built with [Lovable](https://lovable.dev).
